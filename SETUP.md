# Development environment setup

These steps get you from a fresh clone to a running Jupyter kernel in Emacs.
Repeat them on each new workstation.

## Prerequisites

- [uv](https://docs.astral.sh/uv/getting-started/installation/) installed globally
- Emacs with `use-package`, `uv-mode`, `elpy`, `code-cells`, and `emacs-jupyter`
  installed from MELPA

## 1. Install dependencies

From the project root:

```bash
uv sync
```

This creates `.venv/` and installs everything in `pyproject.toml`, including
dev dependencies (`ipykernel`, `jupytext`, etc.).

## 2. Register the Jupyter kernel

This wires the project's exact Python binary into Jupyter's kernel registry.
Use the venv's Python directly (not `uv run`) so the kernel path is written
to your user's global Jupyter directory rather than inside `.venv/`:

```bash
.venv/bin/python -m ipykernel install --user \
    --name flim-pipeline \
    --display-name "FLIM Pipeline"
```

Verify it registered correctly:

```bash
jupyter kernelspec list
# Should show:
# flim-pipeline    ~/.local/share/jupyter/kernels/flim-pipeline
```

> **Note:** The kernel spec records the absolute path to `.venv/bin/python`.
> If you move or rename the project directory, re-run this command to refresh
> the path.

## 3. Configure Emacs

Add the following to your `.emacs` (alongside your existing `uv-mode`/`elpy`
config — no `use-package python` block needed):

```elisp
;; Cell-based execution for jupytext percent-format notebooks
(use-package code-cells
  :ensure t
  :hook (python-mode . code-cells-mode)
  :bind (:map code-cells-mode-map
              ("C-c C-r" . code-cells-eval)
              ("M-n"     . code-cells-forward-cell)
              ("M-p"     . code-cells-backward-cell)
              ("C-c C-b" . code-cells-eval-above)))

;; Jupyter kernel protocol
(use-package jupyter
  :ensure t)

;; Inline image display in the REPL buffer
(add-hook 'jupyter-repl-mode-hook 'iimage-mode)

;; Skip the kernel prompt and always use the project kernel
(setq jupyter-default-kernel "flim-pipeline")
```

## 4. Start a session

Open any `notebooks/*.py` file in Emacs, then:

```
M-x jupyter-run-repl
```

Select `flim-pipeline` when prompted (or it will be pre-selected if you set
`jupyter-default-kernel` above). Then use:

| Key       | Action                        |
|-----------|-------------------------------|
| `C-c C-r` | Run current cell              |
| `C-c C-b` | Run all cells above           |
| `M-n`     | Jump to next cell             |
| `M-p`     | Jump to previous cell         |

## 5. Inline plots (optional)

To display matplotlib output inside the Emacs REPL buffer rather than opening
a window, add this cell at the top of your notebook:

```python
# %%
import matplotlib
matplotlib.use("module://matplotlib_inline.backend_inline")
```

## Notes on the notebook workflow

Notebooks live in `notebooks/` as `# %%`-delimited `.py` files (jupytext
percent format). The paired `.ipynb` files are auto-generated by jupytext and
are excluded from version control via `.gitignore`. Commit only the `.py`
files.

To share results with collaborators who do not use Emacs, hand them the
`.ipynb` or export to HTML:

```bash
uv run jupyter nbconvert --to html notebooks/01_explore.ipynb
```
